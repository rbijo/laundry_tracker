# Security Policy

## Overview
Laundry Tracker is a local-only, free Android application. All application data (wash items, category counts, issue records, and settings) is stored strictly on the local device filesystem. The application does not use a cloud backend, remote database, external authentication, or paid third-party API services.

## Supported Versions
Only the latest released version receives active updates and bug fixes.

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability
If you discover a security issue or vulnerability in Laundry Tracker:

1. **Do not disclose it publicly** (e.g., in public GitHub issues, discussions, or social media) until it has been reviewed and addressed.
2. Submit a report through the repository's security advisories tab or contact the maintainer at [MAINTAINER_CONTACT_PLACEHOLDER].

### What to Include in a Report
To help resolve the issue quickly, please provide:
- A clear description of the vulnerability.
- Steps to reproduce the issue or a proof-of-concept.
- Affected device details (Android version, device model).
- Any potential impact or risk assessment.
